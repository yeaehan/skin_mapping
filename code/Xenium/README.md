# Xenium Workflows

This folder contains Xenium preprocessing, annotation, trajectory, senescence, and plotting workflows.

The preferred long-term structure is:

- `preprocessing/` for data loading, QC, filtering, and object creation
- `analysis/` for annotation, trajectory, and downstream analyses
- root-level files only when they are active notebooks/scripts that have not yet been migrated

See `docs/script_inventory.md` before deleting root-level Xenium files; several are still substantial analysis scripts.
